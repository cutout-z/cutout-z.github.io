The orbital DC stuff is so silly it’s kind of shocking

The size of solar array you need to run a measly 50MW of GPUs is 60x larger than the ISS. Latency is an issue. Maintenance is a massive issue. There are techs swapping spares constantly in regular DCs. Cooling doesn’t work in a vacuum so you need massive radiators.

All of this is a solution looking for a problem. Terrestrial DCs have a few real bottlenecks - but none of them pale in comparison to the can of worms this represents. What is likely to be needed is smaller, localized micro DCs for inference that can take up existing grid capacity or be powered by a small dedicated generation solution
